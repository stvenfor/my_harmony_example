# 页面开发规范

本文档定义了项目中页面开发的统一规范，包括路由管理、页面结构、状态管理等。

---

## 1. 路由管理规范（NavPathStack）

### 1.1 核心原则

**所有新创建的页面必须使用 `NavPathStack` 进行页面跳转和导航管理。**

### 1.2 页面结构要求

每个页面组件必须遵循以下结构：

```typescript
@Component
export struct YourPageName {
  // 1. 必须声明 pathStack（用于页面跳转）
  @Consume('pathStack') pathStack: NavPathStack
  
  // 2. 其他状态变量
  @State someState: type = initialValue
  
  // 3. 生命周期方法（可选）
  aboutToAppear(): void {
    // 初始化逻辑
  }

  build() {
    // 4. 必须使用 NavDestination 包裹页面内容
    NavDestination() {
      // 页面主要内容
      Column() {
        // ...
      }
    }
    // 5. 配置 NavDestination 属性
    .hideTitleBar(true)  // 隐藏默认标题栏（如使用自定义导航）
    .onReady((context: NavDestinationContext) => {
      // 6. 必须在 onReady 中获取 pathStack
      this.pathStack = context.pathStack
    })
    .title('页面标题')  // 设置页面标题
  }
}
```

### 1.3 关键要点

| 要素 | 说明 | 示例 |
|------|------|------|
| `@Consume('pathStack')` | 消费父级提供的 pathStack | `@Consume('pathStack') pathStack: NavPathStack` |
| `NavDestination()` | 页面根容器 | `NavDestination() { ... }` |
| `.onReady()` | 获取 context 中的 pathStack | `.onReady((context) => { this.pathStack = context.pathStack })` |
| `.hideTitleBar(true)` | 隐藏系统标题栏（推荐） | 使用自定义导航时必选 |
| `.title()` | 设置页面标题 | `.title('页面标题')` |

### 1.4 页面跳转方式

#### 方式一：直接使用 pathStack（推荐）

```typescript
// 跳转到指定页面
this.pathStack.pushPathByName('TargetPageName', null)

// 带参数跳转
const params: Record<string, Object> = { 'key': 'value' }
this.pathStack.pushPathByName('TargetPageName', params)

// 返回上一页
this.pathStack.pop()

// 返回到指定页面
this.pathStack.popToName('SomePageName')
```

#### 方式二：使用 RouterModule（全局路由）

```typescript
import { RouterModule } from '@ohos/common'
import { RouterMap } from '@ohos/common'

// 跳转到已注册的路由
RouterModule.push({
  url: RouterMap.HOME_BILL_DETAIL,
  param: { id: 123 }
})

// 返回
RouterModule.pop()
```

### 1.5 完整示例

参考文件：[HarmonyUxExamplesPage.ets](file:///Users/qpy/Desktop/personal/mixture/mixtrue_oh/features/home/src/main/ets/pages/HarmonyUxExamplesPage.ets)

```typescript
import { NavItem, StringConstants } from '@ohos/common'

@Component
export struct HarmonyUxExamplesPage {
  @Consume('pathStack') pathStack: NavPathStack
  @StorageLink(StringConstants.TOP_AREA) topArea: number = 0
  @State counter: number = 0

  build() {
    NavDestination() {
      Column() {
        NavItem({ showBack: true, title: '页面标题' })
        
        Scroll() {
          // 页面内容
        }
        .layoutWeight(1)
      }
      .width('100%')
      .height('100%')
    }
    .hideTitleBar(true)
    .onReady((context: NavDestinationContext) => {
      this.pathStack = context.pathStack
    })
    .title('页面标题')
  }
}
```

```typescript
export enum RouterMap {

```

### 2.2 路由类型定义

在 `common/src/main/ets/utils/router/Types.ets` 中：

```typescript
export interface NavRouterInfo {
  url: RouterMap | DialogMap;
  mode?: NavDestinationMode;
  param?: ESObject;
  onPop?: Callback<PopInfo>;
}
```

```json
    }
  ]
}
```

## 3. 页面状态管理规范

### 3.1 装饰器使用规范

| 装饰器 | 用途 | 示例 |
|--------|------|------|
| `@State` | 组件内部状态 | `@State counter: number = 0` |
| `@Consume` | 消费祖先组件提供的值 | `@Consume('pathStack') pathStack: NavPathStack` |
| `@Provide` | 向后代组件提供值 | `@Provide('pathInfo') pathInfo: NavPathStack` |
| `@StorageLink` | 与应用存储同步 | `@StorageLink(StringConstants.TOP_AREA) topArea: number` |
| `@Prop` | 接收父组件传递的不可变值 | `@Prop title: string` |
| `@Link` | 与父组件双向绑定 | `@Link isVisible: boolean` |

### 3.2 安全区域处理

```typescript
@StorageLink(StringConstants.TOP_AREA) topArea: number = 0
@StorageLink(StringConstants.BOTTOM_AREA) bottomArea: number = 0

build() {
  NavDestination() {
    Column() {
      // 内容
    }
    .padding({ top: this.topArea, bottom: this.bottomArea })
  }
}
```

## 4. 导航栏规范

### 4.1 使用 NavItem 组件

推荐使用 `common` 模块提供的 `NavItem` 组件：

```typescript
import { NavItem } from '@ohos/common'

NavItem({ 
  showBack: true,           // 是否显示返回按钮
  title: '页面标题',         // 标题文本
  backAction: () => {       // 自定义返回逻辑（可选）
    this.pathStack.pop()
  }
})
```

### 4.2 自定义导航栏

如需完全自定义导航栏：

```typescript
Row() {
  Button({ type: ButtonType.Circle }) {
    SymbolGlyph($r('sys.symbol.chevron_left'))
  }
  .onClick(() => {
    this.pathStack.pop()
  })
  
  Text('页面标题')
    .fontSize(20)
    .fontWeight(FontWeight.Bold)
}
.width('100%')
.height(56)
.padding({ left: 16, right: 16 })
```

## 5. 最佳实践

### 5.1 页面命名规范

- 使用 **PascalCase** 命名
- 以 `Page` 结尾（如 `HomePage`, `DetailPage`）
- 名称应清晰表达页面功能

### 5.2 文件组织

```
features/{module}/src/main/ets/pages/
├── HomePage.ets              # 主页
├── DetailPage.ets            # 详情页
└── SettingsPage.ets          # 设置页
```

### 5.3 代码结构顺序

```typescript
@Component
export struct YourPage {
  // 1. 装饰器声明的状态变量
  @Consume('pathStack') pathStack: NavPathStack
  @State someState: type
  
  // 2. 私有成员变量
  private readonly constant: string = 'value'
  
  // 3. 生命周期方法
  aboutToAppear(): void { }
  
  // 4. 业务方法
  private handleAction(): void { }
  
  // 5. @Builder 方法
  @Builder
  private someBuilder() { }
  
  // 6. build 方法
  build() { }
}
```

### 5.4 错误处理

```typescript
private showToast(message: string): void {
  try {
    this.getUIContext().getPromptAction().showToast({ 
      message, 
      duration: 1800 
    })
  } catch (error) {
    console.error(`showToast failed: ${JSON.stringify(error)}`)
  }
}
```

## 6. 常见问题

### Q1: 为什么我的 pathStack 是 undefined？

**A:** 确保在 `.onReady()` 回调中正确赋值：

```typescript
.onReady((context: NavDestinationContext) => {
  this.pathStack = context.pathStack  // 必须这样赋值
})
```

### Q2: 如何在页面间传递参数？

**A:** 使用 `pushPathByName` 的第二个参数：

```typescript
// 发送方
const params: Record<string, Object> = { 'id': 123, 'name': 'test' }
this.pathStack.pushPathByName('TargetPage', params)

// 接收方
aboutToAppear(): void {
  const params = this.pathStack.getParamByName('TargetPage')
  if (params && params.length > 0) {
    const data = params[0] as Record<string, Object>
    console.log('Received:', data['id'])
  }
}
```

### Q3: 如何防止重复点击导致的多次跳转？

**A:** 添加防抖或标志位：

```typescript
@State isNavigating: boolean = false

private navigateTo(target: string): void {
  if (this.isNavigating) return
  this.isNavigating = true
  this.pathStack.pushPathByName(target, null)
  setTimeout(() => {
    this.isNavigating = false
  }, 500)
}
```
