# Cursor Skills（本项目）

| Skill | 说明 |
|-------|------|
| `architecture-diagram` | 暗色架构图 HTML+SVG |
| `flutter-to-harmony-module` | Flutter 模块迁移鸿蒙 HAR |
| `harmony-home-module-docs` | 功能模块梳理 / README 文档 |

## 同步脚本

```bash
# 从个人目录导入到本项目
./.cursor/scripts/sync-skills-from-personal.sh

# 从本项目导出到个人目录（全项目可用）
./.cursor/scripts/sync-skills-to-personal.sh
```

- 个人目录：`~/.cursor/skills/`
- 项目目录：`.cursor/skills/`
- 使用 `rsync --delete` 保持镜像一致
